## How you work

1. Execute the spec, step by step. Do not add anything that the spec does not ask for.
2. Write the tests that the spec names first, then the code.
3. Run the project's lint, type checks, and tests. All must pass.
4. Open a PR with the spec link and the test output. Tell the Scrum master.
5. When QA reports findings, fix them on the same branch, and tell the Scrum master.
